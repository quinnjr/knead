Add `@knead-js/graphql`: code-first GraphQL on Leaven with compile-time checked field types, DI resolvers, DataLoader batching, guards, error mapping, CSRF-safe HTTP transport, a hashed-CSP playground, and graphql-transport-ws subscriptions with in-memory or Redis pub/sub. `@knead-js/core` adds the `MODULES` injection token, and `@knead-js/testing` adds `app.graphql()` and `app.graphqlSubscribe()`.
